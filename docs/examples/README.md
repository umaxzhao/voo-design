Four designs selected from the local VOO project library for the repository introduction. Each source file is a native binary `.voo` document with a saved preview. Text, shapes, paths and chart bars remain editable; the artwork is not a flattened screenshot.

| File | Design | Document canvas |

| [f1-grand-prix.voo](f1-grand-prix.voo) | F1-inspired racing poster and an additional poster study | 1080 × 1440 |
| [pulse-dashboard.voo](pulse-dashboard.voo) | PULSE: business analytics dashboard | 1200 × 900 |
| [form-poster.voo](form-poster.voo) | FORM: typography and geometric brand poster | 1200 × 900 |

## Open and edit

1. Download a `.voo` source file from GitHub using **Download raw file**.
2. Open [VOO Design](https://voo.run/editor/) or the desktop app and choose **Open File**.
3. Select text or a shape in the layer panel to edit it. Select a frame to move a complete composition.

The F1 file includes a second artboard to the right of the document canvas; zoom out to inspect it. The README export shows the primary Monaco poster. Its event copy, performance figures and status labels are illustrative concept content, not event information or a claim of official affiliation. The music interface and dashboard use fictional demonstration content and do not implement playback, payments or live data.
